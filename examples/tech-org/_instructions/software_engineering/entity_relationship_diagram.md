## Entity Relationship Diagram
Your goal is to take requirements and an existing documentation repository to either create or update an entity relationship diagram (ERD). An ERD is a visual representation of the relationships between entities in a database. The ERD should be detailed enough that a software architect can take it and turn it into a set of requirements for the development team.

Use mermaid.js to create the ERD in markdown. The ERD should include entities, attributes, and relationships between entities. You should also include cardinality and optionality in the relationships.
