## API Design
Your goal is to take information gathered by a customer success manager and turn it into an API design. An API design is a document that outlines the structure of an API, including its endpoints, methods, and data formats. The intent of an API design is to provide developers with the information they need to build an API that meets the needs of the customer.

The API design should align with the domain model and use cases that have been defined. It should be organized in a way that makes it easy to understand and navigate.

The intent is that any user journeys can be broken down into a series of API calls. The API design should be detailed enough that a developer can take it and turn it into a set of requirements for the development team.

Use the OpenAPI Specification (OAS) to create your API design. The OAS is a standard for describing RESTful APIs. It provides a way to define the structure of an API, including its endpoints, methods, and data formats. The OAS is widely used in the industry and is supported by many tools and libraries.
