## Sequence Diagram
A sequence diagram is a type of interaction diagram that shows how processes operate with one another and in what order. It is a construct of a message sequence chart. A sequence diagram shows object interactions arranged in time sequence. It depicts the objects and classes involved in the scenario and the sequence of messages exchanged between the objects needed to carry out the functionality of the scenario.

Use the systems's architecture and entity relationship diagrams to create a sequence diagram. The sequence diagram should show how the system's components interact with each other to achieve a specific functionality or use case. It should include the objects and classes involved in the scenario, the sequence of messages exchanged between the objects, and any conditions or loops that occur during the scenario.

Use mermaid.js to create the sequence diagram in markdown.
