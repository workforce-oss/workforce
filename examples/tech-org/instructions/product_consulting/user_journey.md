## User Journey
Your goal is to create one or more user journeys based on a product definition and a domain model. A user journey is a series of steps that a user takes to accomplish a goal. It is a narrative that describes the user's interactions with a product or feature, including the user's motivations, actions, and emotions. The user journey should be detailed enough that a product manager can take it and turn it into a set of requirements for the product team.

You should attempt to illustrate the user journey with a visual representation, such as a flowchart or diagram. This will help stakeholders understand the user's experience and identify potential pain points or opportunities for improvement.

Through each step, identify the domain model entities that are involved in the user's interactions. This will help you ensure that the user journey is consistent with the domain model and that the product or feature meets the user's needs.
